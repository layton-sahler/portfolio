The Tale of Genji

Interactive mapping tool for The Tale of Genji — visualizes where each of the novel's 795 waka poems was sent and received across 130+ location pages. Built on a graph database with an API pipeline powering live data on the frontend. Page content is AI-generated from the source text, backed by a verification system so researchers can check every claim against the original.
